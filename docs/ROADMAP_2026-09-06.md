Este documento é o snapshot operacional de referência. Não apaga roadmaps históricos.

## Baseline

`main` observado após PR #310: `e0afcfd9bb85c54885f89442818a8117f6e1c148`.

PR `#310` foi validado e merged depois de Test Suite, AI Quality Gate e CodeQL terminarem verdes. O PR reforçou a matriz terminal para que os scores das classes terminais sejam observados pelo `alpha_beta()` nativo real, e não por uma fórmula duplicada no helper de teste.

## Regra de sequência

A partir deste snapshot, nenhuma optimização substantiva de Ares pode ultrapassar os gates de correctness abaixo.

```text
C0 state identity
→ C1 canonical action
→ C2 execution
→ C3 independent legal-action oracle
→ C4 cross-backend transition equivalence
→ C5 bridge/protocol
→ pure node-budget semantics
→ A0 PASS
→ A0.1 semantic closure
→ Strength calibration
→ contextual balance
→ search / move ordering / NNUE
```

## Gate 0.1 — Semantic Closure

**Status: IN PROGRESS**

Objetivo: fechar os contratos semânticos que ainda não estão demonstrados como equivalentes entre engine Python, oráculo C3 e backend C++.

```text
repetition / threefold semantics
→ terminal-state parity
→ silence / stun parity
→ all special-spell legality parity
→ canonical legal-action API
→ authoritative execute path
→ differential coverage of those contracts
→ removal of confirmed dead rule code
```

### Trabalho ativo

- [ ] Demonstrar ou corrigir paridade de repetição/threefold entre Python e C++. A idempotência da observação de histórico foi corrigida no issue #294; a identidade de repetição e a representação de histórico no backend nativo continuam em aberto.
- [x] Demonstrar terminal-state parity de forma independente do caminho de pesquisa. PR #310 agora observa os scores das classes terminais através do `alpha_beta()` nativo real e mantém `TWC=49` como controlo não-terminal.
- [x] Tornar explícita e testável a semântica Inquisitor silence ↔ stun; o C3 oracle, o wrapper Python e o movegen C++ concordam e a regressão dedicada está merged em PR #292.
- [x] Cobrir a legalidade de special spells sob um contrato comum; PR #303 fechou também a falha de herança encontrada no guard de silêncio.
- [x] Consolidar `legal_actions()` como API engine-facing adapter em PR #306 e normalizar `execute_action()` através de `normalize_action()` em PR #308.
- [ ] Definir um execute path que rejeite ações ilegais por contrato, sem duplicar a semântica dos geradores. PR #309 permanece como draft enquanto a alteração segura no `GameState` grande não estiver concluída; issue #311 acompanha a continuação.
- [ ] Demonstrar cobertura diferencial de todos os contratos fechados, indo além das matrizes específicas já existentes.
- [x] Remover código de regras comprovadamente inalcançável/dead após a cobertura correspondente (PR `#300`).

### Regra de saída

A0.1 só pode passar quando houver evidência diferencial/invariante suficiente para os itens acima. Só depois se reabre a discussão de Strength calibration.

## Gate 1 — Strength

Próxima fase, ainda bloqueada por A0.1 nesta tranche:

```text
A/A neutrality
→ weaker/stronger controls
→ replicated runs
→ true experimental units
→ contextual coverage
→ calibrated uncertainty
→ SPRT operating characteristics
→ independent promotion gate
```

A implementação deste gate depende de investigação experimental/estatística. Nesta tranche de engenharia não são executadas análises de datasets, estatística ou strength experiments; essas tarefas devem ser delegadas a uma IA especializada quando necessário.

O hold-out protegido não pode orientar tuning.

## Gate 2 — UI

UI pode avançar em paralelo quando a alteração não muda regras, transições ou contratos C0–C5. A validação visual deve continuar separada de correctness e CI.

## Gate 3 — documentação

Cada marco deve actualizar snapshot/roadmap no mesmo bloco documental. Um snapshot antigo nunca deve ser usado para inferir o estado atual do `main`.

## Anti-regressão metodológica

```text
CI verde ≠ correctness total
C3 ≠ C4
C4 ≠ semantic closure
semantic closure ≠ search quality
search quality ≠ strength
benchmark ≠ global gain
snapshot ≠ source of truth if stale
```

Ver `docs/STATE_AND_CRITIQUE_2026-09-06.md` para a crítica que motivou estes gates.
