# RedWar — Backlog de Desenvolvimento

**Autoridade:** [`ROADMAP.md`](ROADMAP.md).

Este ficheiro é mantido apenas por compatibilidade com referências existentes. Não é uma segunda fila de trabalho e não deve receber tarefas novas enquanto o mesmo trabalho puder ser representado no roadmap operacional.

## Como interpretar

- O estado atual está em [`CURRENT_STATE.md`](CURRENT_STATE.md).
- A razão das dependências está em [`PROJECT_REASONING.md`](PROJECT_REASONING.md).
- Os contratos pertencem aos documentos canónicos por domínio.
- A ordem e o próximo trabalho pertencem apenas a [`ROADMAP.md`](ROADMAP.md).

## Regra

Não marcar itens aqui como concluídos de forma independente. Uma conclusão só existe quando `ROADMAP.md` e o documento canónico relevante forem atualizados com a evidência correspondente.

O histórico antigo deste ficheiro fica preservado no Git, mas o conteúdo operacional duplicado foi deliberadamente removido para evitar que uma IA escolha uma lista de tarefas desatualizada.
